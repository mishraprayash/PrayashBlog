## What I work on

Mostly Node.js and NestJS services, PostgreSQL, message brokers, and the Docker and Kubernetes setup they run on, including Dapr sidecars. I also built an [ML request filter in front of Nginx](/projects/nginx-ml-request-filter) to see what it takes to put a model on the request path.

## How I write here

When a post says something breaks, I try to show it breaking: the error, the version, and the code that reproduces it. When I get something wrong, the post says so at the top, with the date and what changed.
